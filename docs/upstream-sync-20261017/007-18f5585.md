The [unit documentation](https://github.com/systemd/systemd/blob/v257/man/systemd.unit.xml) defines a /dev/null unit symlink as a mask that prevents activation, with /etc/systemd/system ahead of ordinary vendor units. Existing wants links do not bypass the mask; this converter therefore preserves the source's mask-only approach. ### Fixed: old persistent upper units could hide all four masks

The source writes only to base /etc. The converter copies the rootfs including /var/lib/overlays/etc/upper; common initramfs mounts that upper over /etc before switch_root. Thus an old upper unit could hide a newly written lower mask, even when converting an image with the lower protections already installed. This repeats the layering issue repaired for the SM8750 installer in review 006.

Apply the four masks to base /etc and an existing upper directory, creating systemd/system within each. Do not create an absent upper. Replacement works for regular unit files, old vendor symlinks and existing masks. Errors are fatal under the converter's existing set -euo pipefail. This is a ten-line product addition; no shared installer or runtime code is changed.
