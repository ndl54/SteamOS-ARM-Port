## Semantic resolutions

1. **Only preserve actual declared sizes.** Source065 tested only whether `ts->prop.max_x/y` was nonzero. Those fields can come from a corrupt controller config even when no size property exists. For example65535x65535 with zero contacts would retain65534/65534 rather than the old4095 defaults. The refined fallback requires a readable u32 size greater than1 per axis; otherwise that axis retains the old default. Partial, missing, unreadable, zero and one-sized properties are handled independently. Normal valid-config behavior is unchanged.
2. **Preserve parsed axis metadata.** Both the old fallback and source065 unconditionally wrote unswapped property maxima into ABS_X/Y after parsing had already swapped/adjusted them. The refined fallback leaves valid declared axes alone, preserving their inversion/minimum/fuzz/swap metadata. Only a missing/unusable axis gets a default maximum, on the correct post-swap ABS axis. No invert/swap flag is added to either Pocket S DT.
3. **Avoid zero or stale native scaling.** The prerequisite ROCKNIX patch could enable a ratio with native_x or native_y zero, then divide by it in finger reports. Its ratio could also survive a retry whose dimensions now matched DT or whose I2C read failed. Clear scale_to_x/y at the beginning of each config read, and enable the existing ratio only with both native dimensions nonzero. Keep the existing ratios, controller reset policy, checksum, IRQ trigger and10-contact default. This adds no guessed native range for zero dimensions and no change to the nonzero oversized-config heuristic. Unknown native ranges can still yield inaccurate touch; avoiding division by zero does not determine the physical range.

These are Goodix invalid-config corrections in the inherited SM8550 stack. No change was made to FocalTech, tablet Novatek, SM8650 S2, controller mappings, display refresh or other product paths. The separate Goodix pen-report path does not use ROCKNIX's finger scaling; no pen correctness or Game Mode pen-support claim is made.
