## Fixes made during integration

1. **SUPER_ONLY could delete existing userdata outputs and accepted Gen 4.** The source's unconditional cleanup removed userdata.img/userdata.simg before its early return, and Gen 4 reached a checksum command for nonexistent super.img. Validate the flag and reject Gen 4 before creating outputs. Preserve userdata files in this mode, skip unnecessary root/home mounts, and require img2simg only for full conversion. Document that the installed modules must already match the kernel; super-only cannot update them.
2. **CSOT DTB retained BOE touch firmware.** The pinned BOE DTS explicitly sets `novatek_ts_boe_fw.bin`; the touch driver consumes `firmware-name`. The source changed display compatibles but copied that firmware property unchanged. Select `novatek_ts_csot_fw.bin` in the generated CSOT DTS, validate its presence and reject leftover BOE references. The existing rootfs installer already supplies this CSOT firmware. The original BOE DTS is unchanged.
3. **Early /etc overlay was unavailable.** The external config requests `CONFIG_OVERLAY_FS=m`, but the supplied common initramfs has no module-loading step and mounts the persistent /etc overlay before starting systemd. Override it to `y` in this wrapper's fragment to preserve the existing early-overlay behavior. This is a source configuration fix; final Kconfig resolution and boot behavior remain untested.

The safe cleanup from 001/002 remains byte-for-byte unchanged, including preservation of busy mount directories and loop devices and correct failure status. Its SHA256 is `11507c64cc9eada7e1c408e667f85c12856a5c38be01e244c7278e32fdff1fc7`.
